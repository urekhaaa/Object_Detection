🔍 AI Object Detection

An AI-powered Object Detection web application built using Python, Streamlit, and Hugging Face Transformers.

## 🚀 Features

- 📷 Upload JPG, JPEG, or PNG images
- 🤖 AI-powered object detection
- 🔍 Detect objects in uploaded images
- ⚡ Simple and interactive Streamlit interface

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| Python | Programming Language |
| Streamlit | Web Application Framework |
| Hugging Face Transformers | AI Object Detection |
| PyTorch | Machine Learning Framework |
| Pillow | Image Processing |

📦 Installation

Install the required libraries:

pip install -r requirements.txt
▶️ Running the Application

Run the following command:

python -m streamlit run objectdetection.py

The application will open in your browser.

💡 How to Use
Launch the Streamlit application.
Upload an image in JPG, JPEG, or PNG format.
Click the 🔍 Detect Objects button.
The AI analyzes the uploaded image.
The detected object results are displayed.
🧠 AI Model

The application uses the Hugging Face Transformers Object Detection pipeline:

pipeline("object-detection")
